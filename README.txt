MDV Portfolio Massive Package

Contents:
- image/portfolio/... : 50 demo projects across 10 categories
- js/portfolio-data.js : project records ready for the site

Integration:
1. Copy the entire image/portfolio directory into your project, merging folders.
2. Replace or merge js/portfolio-data.js with your project file.
3. Clear cache / hard reload.
4. Verify Portfolio menu, filters, modal gallery and 4 languages.

Important:
- All projects are marked as demo.
- No prices are included.
- Images are organized per project folder.
