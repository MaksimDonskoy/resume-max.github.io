# resume-max.github.io

A single-page personal resume website intended for GitHub Pages.

## Project structure

- `index.html` — the site page
- `css/style.css` — site styles
- `js/` — page behavior, theme, and translations
- `image/` — profile photo and image assets
- `files/` — downloadable resume PDFs

Add the actual photo and PDF files when they are available; see the README
files in `image/` and `files/` for the expected filenames.
